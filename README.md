# 五子棋 Five-in-a-row

用 **TypeScript + Canvas + SCSS** 编写的网页版五子棋，零运行时依赖，打开 `index.html` 即可游玩。

## 特性

- **人机对战**：三档难度
  - 简单：只看一步，偶尔会漏掉防守，适合新手
  - 普通：4 层搜索，会进攻也会防守
  - 困难：迭代加深搜索（最多 8 层，限时 1.5 秒），能发现四三、活四等组合杀
- **双人对战**：同一设备轮流落子
- 标准 15×15 棋盘，带坐标与星位；黑方先行，无禁手，五子及以上连珠获胜
- 正确判断横、竖、两条斜线上的五连（包括最后一子落在中间的情况）
- 获胜连线高亮、最后一手标记、可选显示手数、悬停预览落点
- 悔棋（人机模式下会同时撤回电脑的一手）、重新开始、平局判定
- 刷新页面后自动恢复对局与设置
- 自适应布局：电脑、平板、手机均可游玩；支持高分屏与深色模式
- 键盘操作：<kbd>Ctrl</kbd> + <kbd>Z</kbd> 悔棋；棋盘获得焦点后用方向键移动、回车落子

## 运行

```bash
git clone https://github.com/wxrkz123/Five-in-a-row.git
```

直接用浏览器打开 `index.html` 即可（`dist/` 中已包含构建好的文件）。

## 开发

需要 Node.js 22 及以上。

```bash
npm install
```

```bash
npm run build      # 构建 dist/gomoku.js 与 dist/gomoku.css
```

```bash
npm test           # 运行规则与 AI 的单元测试
```

```bash
npm run check      # 类型检查 + 测试 + 构建
```

开发时可分别运行 `npm run watch:js` 与 `npm run watch:css` 自动重新构建。修改源码后请重新构建并一并提交 `dist/`，这样直接打开 `index.html` 的用户也能用上最新版本。

## 目录结构

```
├── index.html             页面结构
├── src/
│   ├── core/

│   ├── ui/
│   │   └── renderer.ts    Canvas 绘制
│   ├── styles/
│   │   └── index.scss     样式
│   └── main.ts            入口：连接对局、AI 与界面
├── test/                  单元测试（node:test）
└── dist/                  构建产物（由 npm run build 生成）
```

## AI 原理简述

1. **棋型识别**：以某点为中心，取一条直线上前后各 4 格。中心以外 8 格各有「空 / 己方 / 阻挡」三种状态，共 3⁸ = 6561 种组合。启动时一次性算出每种组合对应的棋型（连五、活四、冲四、活三、眠三、活二、眠二），运行时直接查表。
2. **落点评估**：某点的分数 = 己方在此落子的价值（进攻）+ 对方在此落子的价值（防守），并识别双四、四三、双活三等组合。
3. **搜索**：对评分最高的若干候选点做 α-β 剪枝的极大极小搜索；对方冲四时只考虑挡点（并且不消耗搜索深度），对方有活三等威胁时只考虑防守点和己方的冲四反击。
